# Семинар 01

База данных - Самодокументированное собрание интегрированных записей.

Запись не лежит отдельно и ее история изменений описывается в логах. У записи есть мета-информация.

СУБД - Система управления базами данных.

## Требования к БД

1. Неизбыточность. 
2. Совместное использование.
3. Эффективность доступа. Минимизировать время операций.

    * OLTP
    * OLAP 

4. Целостность. Непротиворечивость.
5. Безопасность
6. Надежная. Восстановимость после сбоя.
7. Независимость от внешних приложений.

## Функции СУБД

1. Управление данными во внешней памяти.
2. Управление данными в оперативной памяти.
3. Управление транзакциями
4. Журналирование
5. Поддержка некоторого языка (SQL)

## SQL - Structured Query Language

ISO: 2011

* T-SQL
* PL/PG SQL
* PL/SQL

Базируется на реляционной модели: Теория множеств + Логика предикатов

| Attr1 | Attr2 | Attr3 |
| --------------- | --------------- | --------------- |
| 1 | a | true |
| 2 | b | false |
| 3 | c | false |
| 4 | d | true |

Колонка - Аттрибут\
Строка - Кортеж\
Описание аттрибутов - Заголовок отношения\
Набор записей - Тело отношений

* DDL (Data Definition Languange)

    * Создание - Create
    * Изменение - Alter
    * Удаление - Drop

* DNA (Data Manipulation Language)

    * Добавить данные - Insert
    * Удалить данные - Delete/Truncate
    * Изменить данные - Update
    * Посмотреть - Select

* DCL (Data Control Language)

    * Выдать права - Grant
    * Забрать права - Revoke
    * Запретить - Deny

## Способы хранения данных

1. Таблица - Table
2. Временная таблица - Temp table
3. Представление - View

    Example:
    
    employee:
        id | Name | Salary
    
    create view employee as 
        select id,Name
        from employee

4. Материализованное представление - Materialized view
5. Табличные переменная - не является объектом
6. Индексированное представление/Проекция
